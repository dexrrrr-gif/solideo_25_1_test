# 시스템 리소스 실시간 모니터링 시스템

실시간으로 시스템 리소스를 모니터링하고 시각화하여 PDF 리포트로 생성하는 Python 기반 모니터링 도구입니다.

## 주요 기능

### 모니터링 항목
- **CPU**: 전체 사용률 및 코어별 사용률
- **메모리**: 사용률 및 사용량 (GB)
- **디스크**: 사용률, 읽기/쓰기 I/O 속도
- **네트워크**: 송신/수신 트래픽 (MB/s)
- **온도**: CPU 온도 (센서 지원 시)

### 시각화 기능
- 실시간 그래프 업데이트
- 8개의 다양한 차트 (라인, 바, 파이 등)
- 통계 요약 테이블 (평균, 최소, 최대)
- 직관적인 컬러 코딩

### 리포트 생성
- 모니터링 종료 후 자동 PDF 리포트 생성
- 상세 통계 테이블
- 고해상도 시각화 차트
- 요약 및 분석 정보

## 설치 방법

### 필수 패키지 설치
```bash
pip install -r requirements.txt
```

### 필요한 패키지
- psutil: 시스템 정보 수집
- matplotlib: 그래프 시각화
- pandas: 데이터 처리
- reportlab: PDF 생성
- numpy: 수치 계산

## 사용 방법

### 기본 실행 (5분 모니터링)
```bash
python system_monitor.py
```

### 실행 결과
1. **실시간 시각화 창**: 8개의 차트가 실시간으로 업데이트되는 창이 열립니다
2. **콘솔 출력**: 진행 상황 및 현재 통계가 실시간으로 출력됩니다
3. **PDF 리포트**: 모니터링 종료 후 `system_monitoring_report.pdf` 파일이 생성됩니다

## 차트 설명

### 1. CPU 사용률
- 전체 CPU 사용률을 시간에 따라 표시
- 파란색 라인 차트

### 2. 코어별 CPU 사용률
- 각 CPU 코어의 현재 사용률
- 막대 그래프 (사용률에 따라 색상 변경)
  - 녹색: 0-60%
  - 주황색: 60-80%
  - 빨간색: 80-100%

### 3. 메모리 사용률
- 메모리 사용률(%) 및 사용량(GB)
- 이중 축 라인 차트

### 4. 디스크 사용률
- 전체 디스크 사용률
- 파이 차트 (사용됨/여유)

### 5. 디스크 I/O
- 읽기/쓰기 속도 (MB/s)
- 라인 차트

### 6. 네트워크 트래픽
- 송신/수신 속도 (MB/s)
- 라인 차트

### 7. CPU 온도
- CPU 온도 추이 (센서 지원 시)
- 라인 차트

### 8. 통계 요약
- 모든 지표의 현재값, 평균, 최소, 최대
- 테이블 형식

## PDF 리포트 내용

### 페이지 1: 개요
- 모니터링 기본 정보 (시작/종료 시간, 시스템 사양)
- 성능 통계 요약 테이블

### 페이지 2: 시각화 개요
- 6개의 주요 차트
- CPU, 메모리, 디스크, 네트워크 종합 분석

### 페이지 3: 상세 분석
- 세부 분석 차트
- 디스크 I/O 읽기/쓰기 분리
- 네트워크 송수신 분리

## 시스템 요구사항

- Python 3.7 이상
- Linux/Unix 시스템 (온도 센서 지원)
- 최소 2GB RAM
- 그래픽 디스플레이 (X11 또는 Wayland)

## 커스터마이징

### 모니터링 시간 변경
`system_monitor.py`의 `main()` 함수에서 수정:
```python
duration_minutes = 5  # 원하는 분 단위 시간
```

### 업데이트 간격 변경
```python
update_interval = 2  # 원하는 초 단위 간격
```

### PDF 파일명 변경
```python
monitor.generate_pdf_report('custom_report_name.pdf')
```

## 주의사항

- 모니터링 중 창을 닫으면 즉시 종료됩니다
- CPU 온도는 센서가 지원되는 시스템에서만 표시됩니다
- 네트워크 및 디스크 I/O는 초당 변화량을 측정합니다
- 리소스가 제한된 시스템에서는 업데이트 간격을 늘리는 것을 권장합니다

## 문제 해결

### 그래픽 창이 열리지 않는 경우
```bash
export DISPLAY=:0
```

### 온도 센서를 읽을 수 없는 경우
- 대부분의 경우 정상입니다 (센서 미지원)
- "CPU 온도 센서 사용 불가" 메시지가 표시됩니다

### 권한 문제
일부 시스템 정보는 root 권한이 필요할 수 있습니다:
```bash
sudo python system_monitor.py
```
